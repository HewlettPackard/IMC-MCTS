# Code of Conduct

## Expected behavior

Project participants must communicate professionally, critique ideas and code
rather than people, respect differing experience and backgrounds, and protect
private or embargoed research information.

Harassment, discriminatory language, threats, deliberate disclosure of private
information, and sustained disruption are not acceptable.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions,
and project-related public communication.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub
profile. The maintainer may edit or remove content, close discussions, reject
contributions, or restrict participation when needed to protect the project and
its participants.
