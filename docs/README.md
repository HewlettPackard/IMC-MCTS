# Build and edit the documentation

The public documentation is hosted at https://hewlettpackard.github.io/IMC-MCTS/.
GitHub Actions builds these sources and publishes updates from the main branch.

From the repository root, with Python 3.12 or later:

```sh
python -m pip install -r requirements-docs.txt
python -m sphinx -b html -W --keep-going docs _build/docs
python -m http.server 4793 --bind 127.0.0.1 --directory _build/docs
```

Edit index.rst and guide/*.rst. Add new pages to the toctree in index.rst. The
shared navigation and full-text search are generated by Sphinx. Project styling
and accepted logo assets are in _static/; the editable logo is brand/imc-mcts.drawio.

The visual tutorial uses static PNGs interleaved with explanations. Its tree
sources are _includes/search-walkthrough.html, _static/tutorial.css and
_static/tutorial.js. The hardware mapping source is _static/tutorial-mapping.svg.
The page does not execute the tree JavaScript or the architecture simulator.

To regenerate the PNGs on macOS with Playwright and Google Chrome installed:

```sh
node docs/tools/build_tutorial_images.cjs .
```

Then rebuild the docs and inspect the exported figures before committing.
Simulator execution and trained model inputs are not required to build the site.
