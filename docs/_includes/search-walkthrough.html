Step 0 of 4

Start with visits and values

Each node stores its visit count n and accumulated value w for the player to move at that node. The root is Black and has no untried actions. Its children are White. C has an untried action.

Mean return = w / n lies between 0 and 1; accumulated w can exceed 1.

Why select C?

Selection scores use the starting tree, before expansion. From Black’s perspective, Q = 1 − wchild / nchild. Add an exploration bonus with c = 1.414 and N = 13.

UCB = Q + c √(ln N / n). Scores are rounded to three decimals.
